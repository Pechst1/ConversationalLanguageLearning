# Grammar review: A1 band (package G-A1, 2026-10-03)

Shards:
- `app/data/grammar_review/units_A1.json`: 38 units, every TSV column, `review_status=reviewed`.
- `app/data/rule_cards/fr2_A1.json`: 38 rule cards, `rule-cards-v2`.

There are 34 existing units and 4 new ones. The irregular imperatives were folded into `FR2_A12_IMPERATIVE`.

All units, existing and new, got these changes:
- Each has a regex detector. `ADJ_AGREEMENT` was `llm:`; it is now regex (D9).
- Every detector matches all of its own anchors, its x-ray sentence and every example on its rule card. The check uses `detector_span`: apostrophes folded, `IGNORECASE`, fixed expressions skipped.
- Every `xray_marks` span occurs verbatim in its x-ray sentence.
- Traps are written as self-contained French `✗ … → ✓ …` pairs, with no English glosses inside the French. `grammar_units.trap_pairs` shows those pairs to the learner.
- IPA is written `/…/`, never `[…]`, so it cannot collide with the card markup.

## Per unit

- **ETRE**:
  - Core rule now covers vous as the polite singular and ils for mixed groups.
  - New traps: ils est, tu to a stranger, elles for a mixed group.
  - Added an anchor with ils sont.
  - Detector now catches negatives (je ne suis pas, ce n'est) and ce sont.
  - Added the AVOIR contrast partner.
- **AVOIR**:
  - Name now shows the hunger use.
  - Core rule adds chaud/froid/peur and the German mir ist kalt.
  - New traps: je suis froid, and ils sont/ils ont with the z sound.
  - Detector catches negatives.
- **IL_Y_A**:
  - Fixed the x-ray span «une boulangerie...deux cafés», which was not verbatim.
  - Traps cleaned. Ask forms added (Est-ce qu'il y a…). Detector adds y a-t-il.
- **UN_UNE**:
  - Gender examples now contrast with German (la table / der Tisch).
  - New gender traps: un bonne idée, une problème.
- **LE_LA**:
  - The x-ray sentence was odd («les jus, c'est mieux le matin»). It is now «J'aime le thé, mais je déteste l'eau gazeuse et les sodas».
  - Detector no longer fires on object pronouns (je le vois).
  - Over-firing stays inherent: 271 of 641 catalogue sentences.
- **ER_VERBS**:
  - The x-ray used «mangeons», a spelling-change form, and its note «mange + ons» was wrong. Replaced by «dînons».
  - Added the "no am …-ing" trap.
  - Detector exclusions: ne/me/se…, -ir/-re/irregular plurals, subjunctive forms, -aient, participles. This stops it firing on «je ne», «ils partent» and «elle vient». Hits on other units' sentences dropped from 171 to 84 (original 612-sentence corpus).
- **NEGATION**:
  - Core rule states the être exception and spoken ne-dropping.
  - Main trap is now pas une → pas de (German kein).
- **QUESTIONS**:

  - Detector broadened to ils/elles/ça/c'est.
- **QUESTION_WORDS**:
  - Detector missed its own anchor «Qu'est-ce que vous prenez ?»: `qu'est-ce qu\b` never matches before «e». Fixed.
  - Added qui/quoi.
  - New traps: comment tu t'appelles, combien de, d'où.
- **JE_VOUDRAIS**:
  - Traps are now self-contained French (Monsieur, …).
  - Added the voudrai/voudrais spelling trap.
  - Detector covers voudrions/voudriez/voulez-vous.
- **NUMBERS**:
  - Fixed the known misses: «J'ai quarante-deux ans», «J'ai trente ans», «Il est huit heures». Any 2–69 number before a noun now counts, plus the 21–69 compounds and prices. 70+ is excluded so it does not overlap `NUMBERS_BIG`.
  - Anchor «Le bus 21, c'est vingt et un.» replaced by «Il y a vingt et une chambres dans cet hôtel» (shows une).
  - Added the dix-six → seize trap and six/dix pronunciation.
- **ADJ_AGREEMENT**:

  - Added the German predicative trap (elle est content).

## Rule cards (`fr2_A1.json`)

Every card has these fields:
- example (en/de);
- rule (en/de/fr);
- pattern (rows or table);
- contrast;
- more (en/de/fr);
- how (numbered steps);
- 3–4 examples;
- 2–3 traps with why (en/de/fr);
- 2 contrast_with links, all of them valid ids.

The cards reuse the good material from the 24 v1 cards (via the v1→v2 map). Speakers are drawn-cast ids only. Grey `{…}` marks silent endings (parl{ent}, peti{t}, son{t}, fini{s}, peu{x}), and the tables use them to show which forms sound alike.

## Doubts / for integration

- `IMPERATIVE` changed scope. The A1 forge item bank and the séance curriculum have no items yet for sois/aie/veuillez; integration should add some.
- Detectors use Python-only regex features: lookbehinds and the scoped `(?-i:…)`. Only the backend evaluates them today.
- `ADJ_AGREEMENT`'s regex is a presence detector only (D9). It cannot tell «une robe noir» from «une robe noire» when the adjective form is in the list.
- Some anchors use A2-band words in the current lexicon: tarte, réserver, confiture, soupe, taxi, dommage, infirmier, architecte. These words are unavoidable or were already in the original anchors, so they stay. The B-band words were removed: canal, élèves, paix, marcher.
- `QUEL_EXCLAMATIF` and `ER_SPELLING` could equally sit at A2.1. I kept them at A1.2 for the reasons given above.

# Saison 1 · «La clé d'Odile» — les premiers jours d'une vie (modèle réel)

*Relu à la main le 2026-09-30 : les titres des jours 5–7 corrigés d'après le journal (l'ancien rendu reprenait la scène de la veille).*

*Joué par le harnais (`tests/test_season_one.py`), niveau A2.1, langue de l'interface : anglais.*
*Les jours de tentpole sont les pages de la bible, telles qu'un apprenant les rencontre. Les jours générés sont écrits par le vrai modèle (gpt-5-mini : réalisateur, critique, voies de réponse). Les réponses de l'apprenant sont des phrases toutes faites du harnais, pas une vraie conversation — d'où des échanges qui ne se répondent pas toujours.*

# Le Papier, package 1: before and after (2026-10-18)

Phone size (375×812). **Before**: production, this week's Papier, the walk account
(`before-*.png`). **After**: this branch on a local stack (`after-*.png`): the walk API with
La Revue on and daily, Romy's replies and the leads from the real model, every other provider

(«Un jour de grève dans les transports», «Le marché du dimanche à Aligre»); the lead desk
wrote their leads. Without painted pictures the stage shows the place's fallback plate.

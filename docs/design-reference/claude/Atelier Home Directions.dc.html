1Home screen — three directions

What I read in the current build: cream paper (#f1ece1), EB Garamond italic display, Inter UI, hard 1px ink boxes, offset "print block" shadows, red CTA, roman-numeral roadmap, uppercase 10–11px tracked labels everywhere (kicker, meta, nav, buttons). Three type voices (serif italic, grotesk, mono) and boxes-inside-boxes are what make it read as busy.

System for the overhaul (shared by all three): two fonts only — Garamond italic for the one headline per screen, Instrument Sans for everything else, sentence case, no tracked caps. Rounded 16–24px surfaces instead of ruled boxes. The Bauhaus mark's four shapes become the app's playful vocabulary: progress tokens, path nodes, tab icons. One tactile 3D-press button per screen. Red = action, blue = story/info, yellow = reward, ink = done.
